9    ## 1. نظرة عامة
10   
11   برنامج Desktop لإدارة تجارة الخردة والبلاستيك. بيغطي دورة الشغل كاملة: من شراء البضاعة من الموردين، تخزينها في المخازن، بيعها للمصانع، وحتى إدارة الفلوس والعمال.
12   
13   ### هيكل العمل
14   
15   ```
16   مورد ──► مخزن ──► مصنع
17     │        │        │
18     └────► خزنة ◄─────┘
19            │
20         عم داود
21   ```

238  ## 5. الشاشات والوظائف
239  
240  ### لوحة التحكم (Admin فقط)
241  
242  **Stats Cards:**
243  - إجمالي الداخل (هذا الأسبوع) بالطن
244  - إجمالي الخارج للمصانع بالطن
245  - رصيد المخازن الحالي بالطن
246  - مستحقات من المصانع بالجنيه
247  
248  **Cards:**
249  - آخر 8 معاملات (بضاعة / سحب مورد / شحنة مصنع)
250  - أرصدة الموردين (مدين / دائن)
251  
252  ---
253  
254  ### الموردين
255  
256  **قائمة الموردين:**
257  - جدول: الاسم، التليفون، القطاع، الأرضية، النوع
258  - **فلاتر:** الكل | مخازن | عام | + فلتر لكل مخزن على حدة
259  - **Tag:** 🏭 اسم المخزن أو 🌍 مورد عام
260  - إضافة مورد جديد مع اختيار المخزن (اختياري)
261  
262  **حساب المورد:**
263  - معلومات: التليفون، الأرضية، الرصيد الحالي
264  - **تسجيل بضاعة:** الوزن الإجمالي + نسبة الخصم % + سعر الكيلو
265    - كمية الخصم والوزن الصافي بيتحسبوا تلقائي
266  - **سحب فلوس:** المبلغ + طريقة الدفع + ملاحظة
267    - بيتسجل في خزنة المخزن تلقائي (خروج)
268  - **تسوية أسبوعية** (Admin فقط)
269  - **سجل المعاملات:** جدول مع فلاتر + زر تعديل + زر حذف
270  
271  **معادلة الرصيد:**
272  ```
273  الرصيد = الأرضية − إجمالي البضاعة + إجمالي السحوبات
274  موجب = المورد مدين لعم داود
275  سالب = عم داود مدين للمورد
276  ```
277  
278  ---
279  
280  ### المخازن
281  
282  **قائمة المخازن:**
283  - إضافة مخزن + اختيار المسؤول
284  - **عند الإضافة:** بيتعمل خزنة للمخزن تلقائي
285  - **عند الحذف:** بتتحذف الخزنة المرتبطة
286  - إدارة موردي المخزن
287  
288  **تفاصيل المخزن:**
289  
290  **إجمالي البضاعة:**
291  - إجمالي الداخل / الخارج / المتبقي بالطن
292  - تفصيل بالأنواع: أخضر، ألوان، أبيض، زبالة
293  
294  **تسجيل دخول بضاعة:**
295  - اختيار المورد (+ زر إضافة مورد جديد)
296  - الوزن الإجمالي + نسبة الخصم % + سعر الكيلو
297  - بيتسجل في `warehouse_stock_entries` و `supplier_transactions`
298  
299  **تسجيل خروج بضاعة:**
300  - الكميات بالأنواع الأربعة
301  - سعر الشراء / كيلو
302  - **الوجهة:** عم داود أو مصنع (من قائمة)
303  - لو مصنع: بيفتح dialog لبيانات الشحنة الكاملة
304  
305  **Dialog الشحنة للمصنع:**
306  - الوزن الإجمالي عند المصنع
307  - نسبة خصم المصنع %
308  - سعر البيع / كيلو
309  - صافي وزن المصنع + إجمالي البيع (تلقائي)
310  - مجمل الربح = إجمالي البيع − قيمة الشراء
311  
312  ---
313  
314  ### المصانع
315  
316  **قائمة المصانع:**
317  - جدول بكل المصانع + الرصيد
318  
319  **حساب المصنع:**
320  - الرصيد: المصنع مدين لعم داود / العكس
321  - **تسجيل شحنة:** المورد + الوزن + نسبة الخصم % + السعر
322  - **استلام دفعة:** المبلغ + طريقة الدفع + ملاحظة
323    - بيتسجل في خزنة عم داود تلقائي (دخول)
324  - **سجل المعاملات:** التاريخ، النوع، اسم المورد، الوزن الصافي، نسبة الخصم، كمية الخصم، سعر الكيلو، المبلغ + تعديل + حذف
325  
326  ---
327  
328  ### العمال
329  
330  **قائمة العمال:**
331  - اختيار المخزن (أو "عمال حرة")
332  - إضافة عامل + تليفون + أجر يومي
333  - **تسجيل حضور جماعي** بـ checkboxes
334  
335  **حساب العامل:**
336  - ملخص: أيام العمل، إجمالي الأجر، المسحوب، المتبقي
337  - **تسجيل يوم عمل** بأجر محدد
338  - **سحب فلوس** + طريقة الدفع
339    - بيتسجل في خزنة المخزن تلقائي (خروج)
340  - **تسوية** (Admin فقط)
341  - **سجل المعاملات** مع فلاتر + تعديل + حذف
342  
343  ---
344  
345  ### الشحنات
346  
347  **جدول الشحنات:**
348  - رقم الشحنة، المورد، المصنع، الوزن الصافي، سعر الكيلو، الإجمالي، صافي الربح
349  - زر **تفاصيل** بيعرض كل البيانات
350  
351  **شحنة جديدة:**
352  - **المورد:** بيظهر بس الموردين العامين (مش تابعين لمخزن)
353  - **المصنع:** من القائمة
354  
355  **بيانات الشراء من المورد:**
356  - الوزن الإجمالي عند المورد
357  - نسبة خصم المورد %
358  - سعر الشراء / كيلو
359  - صافي وزن المورد + إجمالي الشراء (تلقائي)
360  
361  **بيانات البيع للمصنع:**
362  - الوزن الإجمالي عند المصنع
363  - نسبة خصم المصنع %
364  - سعر البيع / كيلو
365  - صافي وزن المصنع + إجمالي البيع (تلقائي)
366  
367  **مصاريف التشغيل:**
368  - تحميل، عمال، بنزين، نقل، أخرى
369  
370  **النتائج:**
371  ```
372  مجمل الربح = إجمالي البيع − إجمالي الشراء
373  صافي الربح = مجمل الربح − مصاريف التشغيل
374  ```
375  
376  **عند الحفظ بيتسجل في 3 أماكن:**
377  1. `shipments` — الشحنة الكاملة
378  2. `supplier_transactions` — حساب المورد
379  3. `factory_shipments` — حساب المصنع
380

383  ### الخزنة
384  
385  **قائمة الخزن:**
386  - خزنة عم داود (رئيسية)
387  - خزنة لكل مخزن
388  - كل خزنة بتعرض الإجمالي
389  
390  **تحويل بين الخزن (Admin فقط):**
391  - من خزنة → إلى خزنة
392  - نوع الدفع + المبلغ + ملاحظة
393  - بيتسجل خروج من الأولى ودخول للتانية
394  
395  **تفاصيل الخزنة:**
396  
397  **الملخص:**
398  - الإجمالي الكلي
399  - تفصيل: كاش | بنك | محفظة | شيك
400  
401  **تسجيل معاملة:**
402  - الاتجاه: دخول / خروج
403  - نوع الدفع: كاش / بنك / محفظة / شيك
404  - المبلغ + التصنيف + ملاحظة
405  
406  **سجل المعاملات:**
407  - فلاتر: الكل | دخول | خروج | كاش | بنك | محفظة | شيك
408  - تعديل + حذف لكل معاملة
409  
410  **الربط التلقائي:**
411  
412  | العملية | الخزنة | الاتجاه |
413  |---------|--------|---------|
414  | سحب مورد | خزنة المخزن | خروج |
415  | تسوية مورد | خزنة المخزن | خروج |
416  | سحب عامل | خزنة المخزن | خروج |
417  | دفعة من مصنع | خزنة عم داود | دخول |
418  | تحويل بين خزن | الاتنين | خروج + دخول |

491  ## 8. ملاحظات تقنية
492  
493  ### RTL
494  في `Main.java` فيه Window listener بيطبق `RIGHT_TO_LEFT` على أي نافذة بتتفتح تلقائي.
495  
496  ### التواريخ
497  لازم `CURRENT_DATE` مش `date('now')` — الأخيرة SQLite مش PostgreSQL.
498  
499  في الاستعلامات اللي بتقارن تواريخ محفوظة كـ TEXT:
500  ```sql
501  WHERE entry_date::date >= CURRENT_DATE - INTERVAL '7 days'
502  ```
503  
504  ### نسبة الخصم
505  كل الشاشات دلوقتي بتاخد **نسبة مئوية** وبتحسب الكيلو:
506  ```java
507  double dedKg = gross * (pct / 100.0);
508  double net = gross - dedKg;
509  ```
510  
511  ### ComboBox مع Objects
512  لازم `setCellFactory` و `setButtonCell` عشان يعرض الاسم:
513  ```java
514  combo.setCellFactory(lv -> new ListCell<>() {
515      @Override
516      protected void updateItem(Supplier item, boolean empty) {
517          super.updateItem(item, empty);
518          setText(empty || item == null ? null : item.getName());
519      }
520  });
521  ```
522  
523  ### العمال الحرة
524  `warehouse_id = NULL` مش `0` — لأن الـ foreign key مش بيقبل صفر:
525  ```java
526  if (warehouseId == null) stmt.setNull(3, Types.INTEGER);
527  else stmt.setInt(3, warehouseId);
528  ```
